# Feedback dumps

Human-written notes for the BIOBUZZ chats. One file per dump, named
`<nnn>-<lane>.md` (`000-solver-compare.md`, `001-physics.md`, `T0-field.md`, …).

Rules:

- The human writes above the first `## Response` heading; Claude appends below it, one
  `## Response <short-sha>` per iteration, and never edits the human's text.
- Refer to gallery cells by caption (`pile-fast@120`) so both sides mean the same picture.
- A dump titled `signoff` freezes the behaviour it names.
- Phone photos, manual excerpts, and screenshots live beside the `.md` that cites them.
